# Интернет-магазин спортивного питания «Атрибут»

Учебный проект интернет-магазина, выполненный в рамках курсовой работы. В проекте есть каталог товаров, корзина, регистрация и авторизация пользователей, панель администратора и оформление заказа с отправкой подтверждения по электронной почте.

## Запуск

1. Установите [Node.js](https://nodejs.org/) версии 20.6 или новее.
2. Перейдите в папку `my-shop-server` и выполните `npm install`.
3. Скопируйте `.env.example` в `.env` и при необходимости заполните настройки почты.
4. Скопируйте `users.example.json` в `users.json`.
5. Запустите сервер командой `npm start`.
6. Откройте `http://localhost:3000/Атрибут.html`.

Файлы с пользователями, локальные почтовые настройки и установленные зависимости не добавляются в репозиторий.
